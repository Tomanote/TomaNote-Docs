Most of TomaNote can be driven from the keyboard. Press `Alt+/` at any time to open the shortcuts help overlay, or click the **Keyboard shortcuts** button in the left sidebar.

## Navigation

| Shortcut | Action |
| --- | --- |
| `Ctrl+K` | Command palette (search notes) |
| `Alt+S` | Open settings |
| `Alt+/` | Open / close shortcuts help |
| `Esc` | Exit tab name editing / deselect the active tab |

## Tabs

| Shortcut | Action |
| --- | --- |
| `Alt+N` | New tab |
| `Alt+W` | Close active tab |
| `Alt+,` | Previous tab |
| `Alt+.` | Next tab |
| `Alt+1` … `Alt+9` | Jump to tab 1 … 9 |
| `Alt+T` | Rename active tab |
| `Alt+P` | Pin / unpin active tab |
| `Alt+Backspace` | Delete active tab (with confirmation) |

## Editor

| Shortcut | Action |
| --- | --- |
| `Ctrl+S` | Save (instant feedback) |
| `Ctrl+B` | Bold (three-state cycle) |
| `Ctrl+I` | Italic * |
| `Ctrl+U` | Underline * |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy / cut / paste (plain text) |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Tab` | Insert 4 spaces |
| `Alt+E` | Toggle editor width (default / stretch) |

\* Browser-dependent: see [Editor & formatting](/guides/editor/).

## Notes

- **Desktop only** — shortcuts are enabled on devices with a fine pointer (mouse/trackpad); touch devices use the toolbars instead.
- **Both Alt keys work** — `Alt+N` works with the left or right Alt key.
- **Top-row keys** — the comma, period and number shortcuts use the top-row keys; the numeric keypad is ignored for them.
- **Windows AltGr** — AltGr sends Ctrl+Alt together, so Alt shortcuts won't trigger through AltGr.
- **`Ctrl+U` on Chrome** may open "View Source" instead of underlining (see [issue #67](https://github.com/Tomanote/TomaNote/issues/67)).
- **`Esc` inside the editor** deselects/closes the active tab — don't be surprised!
