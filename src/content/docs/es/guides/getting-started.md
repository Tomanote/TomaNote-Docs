TomaNote es una aplicación web de notas minimalista y offline-first.

## Crear una nota

- Abre TomaNote y empieza a escribir en el editor para crear una nota nueva.
- Tus notas se guardan automáticamente en el almacenamiento local del navegador.

## Organizar tus notas

- Usa las pestañas para gestionar varias notas a la vez.
- Fija tus pestañas favoritas para tenerlas siempre a mano.
